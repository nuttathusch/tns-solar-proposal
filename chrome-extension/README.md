# ⚡ TNS SolarEdge 1-Click Sync (Chrome Extension)

ส่วนขยาย Google Chrome สำหรับเชื่อมต่อ **SolarEdge Designer** เข้ากับ **TNS Solar Proposal Studio** อัตโนมัติใน 1 คลิก!

---

## 🌟 ความสามารถ (Key Features)

- 🚀 **1-Click Sync**: มีปุ่มลอยสีเขียว `⚡ Sync to TNS Proposal` บนหน้า SolarEdge Designer
- 📸 **Auto Snapshot**: ดูดภาพ 2D Top-down Layout และโมเดล 3D จาก SolarEdge อัตโนมัติโดยไม่ต้องแคปภาพหน้าจอ
- 📊 **Auto Extract Data**: ดึงชื่อลูกค้า, ที่อยู่, กำลังผลิต (kWp), จำนวนแผง (Modules), และหน่วยผลิตไฟฟ้าต่อปี (MWh)
- 🔄 **Direct Bridge**: ส่งข้อมูลเข้าสู่เว็บ [https://nuttathusch.github.io/tns-solar-proposal/](https://nuttathusch.github.io/tns-solar-proposal/) ทันที

---

## 🛠️ วิธีติดตั้งส่วนขยายลง Google Chrome (ทำเพียงครั้งเดียว ใน 30 วินาที)

1. เปิด Google Chrome แล้วพิมพ์ในแถบที่อยู่:
   ```text
   chrome://extensions/
   ```
2. เปิดสวิตช์ **"โหมดนักพัฒนาซอฟต์แวร์ (Developer mode)"** ที่มุมขวาบน
3. คลิกปุ่ม **"โหลดส่วนขยายที่ยังไม่ได้แพ็ก (Load unpacked)"** ที่มุมซ้ายบน
4. เลือกโฟลเดอร์:
   ```text
   /Users/nuttathuschaiwut/.gemini/antigravity/scratch/tns-solar-proposal/chrome-extension
   ```
5. เรียบร้อย! ไอคอน **TNS SolarEdge Sync ⚡** จะปรากฏในแถบส่วนขยายของ Chrome ทันที

## 🎯 วิธีใช้งาน:
1. เข้าเว็บ **[designer.solaredge.com](https://designer.solaredge.com)** และออกแบบหลังคาวางแผงตามปกติ
2. กดปุ่มสีเขียว **"Sync to TNS Proposal"** ที่มุมขวาล่าง หรือคลิกไอคอนส่วนขยายบน Chrome
3. ระบบจะดูดรูป 2D/3D และสเปกทั้งหมด วิ่งเข้าหน้า Proposal ของคุณทันที 100%!
