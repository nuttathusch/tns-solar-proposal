# ☀️ TNS Solar Proposal Studio

ระบบเว็บแอปพลิเคชันสร้างและจัดการเอกสารเสนอโครงการ Solar Rooftop อัตโนมัติสำหรับ **TNS SOLAR SYSTEM (TNS network solutions Co., Ltd.)**

---

## 🚀 ฟีเจอร์หลัก (Key Features)

- ⚡ **Smart Solar Sizing & ROI Calculator**: คำนวณขนาดติดตั้งแนะนำ (kWp), จำนวนแผง **LONGi Hi-MO X10 650W N-Type**, ผลประหยัดค่าไฟต่อเดือน/ปี และระยะเวลาคืนทุน (Payback Period & 25-Year Cumulative Return)
- 🔄 **Multi-Option Comparison**: รองรับการเสนอราคา 1 ระบบ หรือ เสนอเปรียบเทียบ 2 แบรนด์ในเล่มเดียว (Huawei SUN2000 vs ATMOCE Microinverter vs Enphase)
- 📐 **SolarEdge Designer & Media Manager**: ปุ่มลัดเปิด SolarEdge Designer และ Google Maps พร้อมช่องอัปโหลด/วางรูปภาพ (Ctrl+V / Paste) สำหรับภาพ 2D Top-down, 3D Isometric, ภาพบ้านหน้าปก และบิลค่าไฟ
- 📄 **Built-in Specsheet & References**: รวมโบรชัวร์แผง LONGi 650W, สเปก Inverter + Mobile App, ตารางรับประกัน 15/30 ปี, แผนบำรุงรักษาประจำปี 9 รายการ, และ Portfolio ผลงานจริง
- 🖨️ **1-Click High-Quality PDF Export**: จัดหน้า A4 ตรงตาม Corporate Identity ของ TNS พร้อมพิมพ์และส่งออกเป็น PDF ทันที

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Typography**: Google Fonts (Prompt, Kanit, Sarabun, Inter)

---

## 📦 การติดตั้งและรันในเครื่อง (Installation & Run)

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มรัน Development Server
npm run dev

# 3. Build สำหรับ Production
npm run build
```

เปิดเว็บเบราว์เซอร์ไปที่ `http://localhost:5173/`
